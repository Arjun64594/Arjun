# Devika E.K.S - Software & Gen AI Developer Portfolio

A modern, high-performance developer portfolio built with React 19, TypeScript, and Tailwind CSS. Showcases expertise in React, Java, Spring Boot, MERN Stack, and Generative AI.

## Quick Start (Run Locally)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🚀 Free Deployment to GitHub Pages

This project is already pre-configured for GitHub Pages:
- `base: './'` in `vite.config.ts` ensures asset URLs work on subpaths.
- `.github/workflows/deploy.yml` contains the GitHub Actions workflow.

### Steps:
1. Initialize Git & push to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   git branch -M main
   git remote add origin https://github.com/DevikaEKS/portfolio.git
   git push -u origin main
   ```

2. In your GitHub repository:
   - Click **Settings** > **Pages**
   - Under **Build and deployment > Source**, choose **GitHub Actions**

3. Your website will automatically build and publish at:
   `https://devikaeks.github.io/portfolio/`
